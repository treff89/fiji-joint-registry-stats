# Fiji National Joint Replacement Registry — public statistics

This repository holds **only** the public website of the Fiji National Joint Replacement Registry (FNJRR):
approved, de-identified, aggregate statistics and the annual report.

- It contains **no patient-level data**, no names, hospital IDs, dates of birth or surgeon names.
- Counts from 1 to 4 are shown as “<5”.
- Files in `public_site/` are generated and published by the registry application (Admin → Publish public statistics).
  Do not edit them by hand.
- Every publish runs an automatic check that refuses files containing anything resembling a patient identifier.

> The statistics currently shown are **synthetic demonstration data**.

Website: https://treff89.github.io/fiji-joint-registry-stats/
